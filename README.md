
# NGO–CSR Match Scorer

A data-driven recommendation and scoring system designed to match NGOs with suitable CSR opportunities based on organizational compatibility and impact-related parameters.

## Features
- NGO and CSR profile analysis
- Compatibility scoring
- Ranking mechanism
- Data filtering and preprocessing
- Visualization of matching insights

## Tech Stack
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Matplotlib

## Objective
The goal of this project is to simplify and optimize collaboration opportunities between NGOs and CSR initiatives using data analysis and scoring techniques.
